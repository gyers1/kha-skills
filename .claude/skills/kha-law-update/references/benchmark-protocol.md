# 2단계 회귀검증

## 목적

`kha-law-update`가 샘플 문장을 암기하는지, 실제 원문에서 같은 **선별·재구성 과정**을 재현하는지 검증한다.

## 검증 자료

```text
SOURCE_DIR/(법령안) 소득세법 일부개정법률(안).md
SOURCE_DIR/(법령안) 조세특례제한법 일부개정법률(안).md
SOURCE_DIR/(법령안) 법인세법 일부개정법률(안).md
SOURCE_DIR/(법령안) 종합부동산세법 일부개정법률(안).md
```

`SOURCE_DIR`은 검증 실행 시 사용자가 제공하는 실제 경로다. **특정 PC의 절대경로를 존재조건으로 삼지 않는다.**

비교 기준

- 형식 비교: `samples/2026세법개정안-법률.md`
- 사실 검증: 위 입력 법령안 (**항상 원문이 기준**)
- 알려진 오류: `sample-notes.md` 2절

사용자가 별도 원본 샘플을 제공하면 스킬 내 복사본과 동일한지 먼저 확인한다.

---

## 단계 A — 넓은 1차 초안

### 실행 조건

- 네 법령안이 개정문·신구조문대비표·부칙을 포함하는지 먼저 확인한다.
- **샘플을 보지 않은 상태에서** 후보 조문 전수표를 만든다.
- 기본 법령별 모드로 작성하고, 교차법령 통합은 제안만 한다.

### 합격 기준

**다음 조문군이 모두 후보에 잡혀야 한다.** 조(條) 단위와 항(項) 단위를 함께 본다.

| 법령 | 필수 후보 |
| --- | --- |
| 소득세법 | **§95(①②③④⑥⑦⑧⑨⑫)**, §103, §104(①·⑦·⑧), §12제2호나목, §25①, §52·§52⑤ |
| 조세특례제한법 | §71의2, §71의3, §95의2, §97, §97의2, §97의10, §97의11, **§97의12**, §98, §98의9, §104의19, §133② |
| 법인세법 | §55의2① |
| 종합부동산세법 | §7, §8(①②③⑦), **§9(①②⑤⑦~⑫)**, §10, §13, §14, §15, §20의2 |

> 소득세법 §95①②③⑥(장특공제 이원화·공제율·한도)과 종부세법 §9①②⑤(세율체계·공제한도)는 **샘플의 1·2순위 항목**이다. 항 단위 목록만 보고 본체 항을 빠뜨리지 않는다.

그 밖의 합격 조건

- 샘플에 빠진 주택임대·주택금융·월세·납부유예·토지 과세 경계 항목도 후보에 나타난다.
- 각 후보에 조문, **개정·신설·삭제·이동** 여부, 핵심 수치, 시행·적용 근거, **출처 태그**가 연결된다.
- 협회 영향·평가·대응계획이 없다.
- 공고번호처럼 법령안 밖 정보를 추정하지 않는다.

### 실패 사례

- 샘플과 똑같은 여섯 대번호만 처음부터 출력한다.
- 개정이유·주요내용 목차만 읽어 §97·§97의10·§104의19·§98의9 등 **목차에 없는 개정**을 놓친다.
- 주택사업자에게 직접 적용되지 않는다는 이유로 수요자 세제와 거래 특례를 전부 제외한다.
- 부칙 없이 날짜를 확정한다.
- `sample-notes.md` 2절의 오류를 그대로 재현한다.

## 단계 B — 사용자 선별 후 수렴

### 모의 사용자 결정

1. 임대소득 비과세, 간주임대료, 주택임차·저당차입금 공제, 월세 공제, 납부유예 등 **개인 납세·주거비 항목은 제외**한다.
2. 세제개편이라는 공통 정책 아래 **정책주제별 통합모드를 승인**한다.
3. 장기공제, 다주택 중과, 1주택자·고령자·세컨드홈, 종부세 체계, 특례 정비, 거주기간 인정, 공급용 토지, 비사업용 토지, 지방 미분양을 중심으로 압축한다.
4. 복잡한 전체 시행일은 별첨 참조로 처리하는 것을 승인한다.
5. **샘플에서 빠진 직접 관련 신설조문은 제외 지시가 없으므로 남긴다. 배치는 다음과 같다.**
   - 조특법 §97의12(공공주택 현물보상분양권) → 󰊵 공급지원 소항목
   - 소득법 §95⑧·§95⑫ → 󰊱 양도소득세 소항목
   - 종부법 §9⑫(세액공제 신청주의) → 󰊲 종합부동산세 `※` 주석
   - 종부법 §9⑦5·6호(특례주택 공제 제외) → 󰊶 지방 미분양 `※` 주석

### 합격 기준

- 대번호 흐름이 다음에 실질적으로 수렴하되, 원문상 중요한 누락은 적절한 대번호 아래 보완된다.
  1. 양도소득세 → 2. 종합부동산세 → 3. 과세특례 요건 조정 → 4. 비거주기간의 거주기간 인정 → 5. 주택공급 지원 및 비사업용 토지 과세 → 6. 지방 준공후 미분양주택 지원
- 여러 조문이 같은 정책항목 아래 정확히 통합된다.
- 독자가 자기 값을 대조해야 하는 수치만 표, 나머지는 문장·각주로 표현된다.
- 각 제목에 근거 조문과 개정유형이 있다.
- 제목이 담은 대상·세목·개정방향을 본문이 반복하지 않는다.
- 원문에서 확인되지 않는 정보는 `추가 자료 필요`로 분리된다.
- **`sample-notes.md` 2절의 오류가 모두 교정된다.** 최소한 다음 6건:
  `§104⑦ 개정·⑧ 신설` / ’26.5.10.+신고시점 조건 / §97의11 시행일 2028.1.1. / §13 토지분 분리 / §97의2 인용 / 공정시장가액비율의 출처 표시
- 샘플에서 빠진 직접 관련 신설조문을 승인 없이 삭제하지 않는다.

## 단계 C — 샘플 자체의 정확성 감사

샘플을 정답지로 간주하지 않는다. 먼저 `sample-notes.md` 2절의 각 항목을 **원문으로 재검증**하고, 그 밖의 오류도 독립적으로 찾는다.

- 조문 표기가 실제 개정문 구조와 일치하는가 (개정/신설/삭제/이동)
- 수치가 개정문·대비표 또는 명시된 보조자료에서 확인되는가
- 샘플에서 빠진 관련 조문이 의도적 제외인지 단순 누락인지
- 시행일·적용례가 부칙과 일치하는가. 상위 법률과 하위 법령의 시행일이 뒤섞이지 않았는가
- 예외 조항의 괄호 제한이 유지되었는가
- 쉬운 설명이 법적 의미를 바꾸지 않았는가

## 시행령 회귀검증 (보조)

시행령 3건(소득령·법인령·종부령)으로도 검증할 수 있다. 기준은 `samples/2026세법시행령개정안.md`.

- 법령별 구성 유지, 순서는 소득 → 종부 → 법인
- 조문 하나 = 항목 하나
- 표 없이 항목당 `◦` 1줄 + `*` 1줄
- 필수 반영: 매입임대아파트 적용기한 예외의 `(’26년말 기준 조정대상지역은 제외)`, 리츠 2건의 계약금 납부분 포함, 취득 시기 하한 4건(’24.1.10. / ’24.3.28. / ’25.1.1.)
- 금지: 대상 법령 밖(조특법 등) 내용 혼입, 제공 자료에 없는 상위 정책명

- 단계 C: 통과/확인필요/실패

### 주요 발견사항

### 누락 후보
| 조문 | 내용 | 1차 초안 반영 여부 | 판단 |

| 구분 | 샘플 | 재현 결과 | 차이의 원인 |
