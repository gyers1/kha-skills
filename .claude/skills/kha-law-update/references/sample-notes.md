# 확정 샘플의 편집원리와 확인된 오류

`samples/` 폴더의 샘플은 **형식·편집판단의 기준**이지 법적 사실의 권위가 아니다.

- **1절**은 샘플이 실제로 어떻게 구성되었는지의 기록이다. 있는 그대로 적는다.
- **2절**은 원문 대조로 확인된 오류다. **재현하면 회귀검증 실패로 판정한다.**
- **3절**은 샘플에서 빠졌으나 1차 초안에는 반드시 올려야 할 후보다.

---

## 1. 샘플이 실제로 구성된 방식

### 1.1 「2026년 세제개편안」후속 세법 개정안 (법률 4건, 정책주제별 통합모드)

법령별이 아니라 세제개편이라는 공통 정책 아래 효과별로 재구성했다.

| 대번호 | 샘플이 인용한 조문 | 묶은 이유 |
| --- | --- | --- |
| 󰊱 양도소득세 | 소득법 §95①②·③⑥신설, §103①, §104⑦, 조특법 §71의2·§71의3 | 주택 양도 단계의 공제·중과·이전지원을 한 흐름으로 제시 |
| 󰊲 종합부동산세 | 종부법 §7①, §8①, §9⑤, §10, §13①② | 보유세의 과세대상·공제·세율·상한을 하나의 비교체계로 |
| 󰊳 과세특례 요건 조정 | 조특법 §97의11 신설, §97·§98 | 기존 임대·미분양 특례의 폐지·기한설정을 별도 영역으로 |
| 󰊴 비거주기간의 거주기간 인정 | 소득법 §95⑦⑨ 신설 | 세목 대번호 어디에도 못 넣는 규정이라 독립 |
| 󰊵 주택공급 지원 및 비사업용 토지 과세 | 조특법 §97의10·§104의19, 법인법 §55의2①, 종부법 §14① | 여러 법에 흩어진 토지 지원·과세를 통합 |
| 󰊶 지방 준공후 미분양주택 지원 | 조특법 §98의9 | 회원사 관심도가 높은 독립 특례라 마지막에 부각 |

> 위 표는 **샘플의 실제 인용을 그대로 옮긴 것이다.** 이 중 일부는 부정확하며 교정 내용은 2절에 있다.

### 1.2 배열·통합의 실제 논리

- **독립 대번호 승격(󰊴)**: 부득이한 사유의 거주기간 인정은 소득법 §95⑦, 종부법 §8②·§9⑩에 **동일 구조로 병렬 신설**되었다. 양도세·종부세 어느 대번호에도 넣을 수 없어 밖으로 뺐다.
  → 재현 규칙: **동일 정책수단이 2개 이상 세목에 병렬 신설되면 독립 대번호로 격상한다.**
- **통합(󰊵)**: 세목 4개(종부세·양도세·법인세)와 정책방향 2개(지원·중과)가 섞였는데 유일한 공통분모가 **과세객체 = 토지**였다.
  → 재현 규칙: 통합 기준은 분량이 아니라 **과세객체 → 세목 → 회원사 이해관계**다.
- **분량이 통합 기준이 아닌 증거**: 󰊶은 불릿 1개로 가장 짧은데 독립 대번호다. 회원사 관심도가 높기 때문이다.

### 1.3 「주택 관련 세법 시행령 개정안」 (시행령 3건, 법령별 구성)

- 법령별 구성 + 법령 끝 `※ 시행일` 한 줄
- 순서: 소득세법 → 종합부동산세법 → 법인세법(개인 세제 우선, 법인 후순위)
- 조문 하나 = 항목 하나의 입도
- **표 없음.** 적용기한 예외 3사유는 `(예외* 해당 시 1년 연장)` + 각주 한 줄로 처리
- 제목·본문·주석 역할 분리를 적용해 항목당 `◦` 1줄 + `*` 1줄

### 1.4 두 샘플에 공통된 편집 이력

1. 정책 발표 요약 → 실제 개정안 요약. 제목마다 근거 조문을 붙였다.
2. 추진 배경을 사실 중심으로 축소(후속조치·예고일·대상 법령·공고번호만).
3. 복잡한 변화만 표로 전환. 연도·주택 수·과세표준처럼 **독자가 자기 값을 찾아야 하는 것**만 남겼다.
4. 묻힐 세부규칙을 독립 항목으로 승격.
5. 평가·전문가 의견·협회 계획은 삭제.

## 2. 확인된 오류 — 재현 금지

원문(개정문·신·구조문대비표·부칙) 대조 결과다.

### 2.1 사실오류

| 샘플 표현 | 원문 확인 결과 | 새 산출물 처리 |
| --- | --- | --- |
| `다주택자 중과 완화(소득법 §104⑦ **신설**)` | 개정문 "제104조제7항 각 호 외의 부분 **후단을 단서로 하여** 다음과 같이 한다" → §104⑦은 **개정**. 신설은 §104⑧(2년 미만 보유 비교과세) | `§104⑦ 개정·⑧ 신설` |
| `※ 2년 이상 보유, ’26년 중 중과를 적용받은 양도분도 포함` | ① §104⑦ 단서는 "보유기간 등을 고려하여 **대통령령으로 정하는 주택**" — 2년은 법률안에 없음<br>② §104⑧은 2년 미만 시 완화세율 **배제가 아니라** 단기세율과 **비교하여 큰 세액**<br>③ 부칙 적용례②는 `2026.5.10.~12.31. 양도분 중 **법 시행 이후 예정·확정신고**하는 경우`에 한정 | 기간 하한(5.10.)과 **신고시점 조건**을 함께 표시. "이미 중과 적용받은 자도 소급"으로 읽히지 않게 쓴다 |
| 매입임대아파트 특례 `’26.10.1. 시행` | 조특법 부칙 §1 2호 → §97의11은 **2028.1.1. 시행**. 부칙 §34 적용례 → 2028.1.1. 이후 양도분. §97의11④ 적용기간 = 2028.1.1.~12.31.<br>**’26.10.1.은 소득·법인·종부 시행령의 시행일이다** | 법률과 시행령의 시행일을 뒤섞지 않는다 |
| 종부세 **주택** 항목에 `§13①②` 인용 | §13은 **토지분** 과세표준 조항 | 주택분은 §8, 토지분은 §13으로 분리 |
| 특례기한 설정 근거를 `조특법 §97·§98`만 표시 | **§97의2**도 동일 패턴(2031/2029 기한)으로 개정됨 | `§97·§97의2·§98` |
| 종부세 세액공제 근거를 `§9⑤`만 표시 | 보유→거주 전환은 §9⑧, ’27년 비교는 §9⑨, 거주간주는 §9⑩ | 근거 조문을 모두 인용 |

### 2.2 법률안만으로 확정할 수 없는 표현

| 샘플 표현 | 법률안에서 확인되는 범위 | 처리 |
| --- | --- | --- |

| 세컨드홈 `지방 전지역(광역시 제외)` | 조특법 §71의2①3호 신설 문언은 "수도권 밖의 지역으로서 제1호·제2호에 해당하지 않는 지역". **광역시 제외는 없음** | 하위법령·상세본 근거가 있을 때만 사용 |
| 공고번호·입법예고일 | 4개 법령안 본문 밖의 정보 | 입법예고문이 제공된 경우에만 사용 |
| 부득이한 사유의 세부 예시(전학·해외체류·부모봉양) | 소득법 §95⑦1호는 "취학, 근무상의 형편, 질병의 요양, 그 밖에 부득이한 사유" | 법률에 없는 예시는 시행령안 근거가 있을 때만 |
| 복잡한 시행일의 `별첨 참조` | 별첨이 제공되어야 확인 가능 | 승인과 실제 별첨이 있을 때만. **일반 산출물의 기본값이 아니다** |

## 4. 압축 시 주의할 조건

- 고령자 지방이전 감면은 연령·1주택 외에 **거주기간 5년·양도일 현재 2년 계속거주·6개월 내 이주·5년 내 재취득 추징**이 있다.
- `2년 이상 보유 주택 한정`이라고 단정하지 않는다. 소득법 §104⑧은 2년 미만 주택에 대해 **중과세액과 단기보유 세율 세액 중 큰 금액**을 적용한다.
- 예외 조항의 **괄호 제한**을 빠뜨리지 않는다. 예: 매입임대아파트 적용기한 연장의 "조정대상지역 신규 지정" 사유에는 `(’26.12.31. 기준 조정대상지역은 제외)`가 붙는다.
- 부속 조항을 모두 제목에 나열할 필요는 없으나, **적용대상이나 추징 여부를 바꾸는 조건은 본문 또는 `*`에 남긴다.**

## 사용 원칙

1. 샘플은 대번호 흐름·결론형 제목·표 선택·압축 정도만 참고한다.
2. 숫자·조문·시행일·적용례는 매 작업의 원문에서 다시 확정한다.
3. 샘플과 원문이 다르면 원문을 따르고 차이를 사용자에게 알린다.
4. 회귀검증은 샘플의 오류까지 재현하는지가 아니라, **샘플형 구조로 수렴하면서 오류를 교정하는지**를 본다.
