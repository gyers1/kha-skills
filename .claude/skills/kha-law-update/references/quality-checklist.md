# 내부 품질점검표

점검 결과를 사용자에게 그대로 노출하지 않는다. 미해결 항목만 별도로 알린다.

## 1. 입력 완전성

- [ ] 모든 대상 법령의 개정문이 있다.
- [ ] 모든 대상 법령의 신·구조문대비표가 있다.
- [ ] 시행일·적용례 작성에 필요한 부칙이 있다.
- [ ] 변환 오류, 누락 페이지, 깨진 표가 없다.
- [ ] **이번 산출물의 대상 법령 범위가 확정되어 있고**, 참고용으로 받은 다른 자료와 구분된다.

## 2. 후보 조문 커버리지

- [ ] 개정이유·주요내용 목차가 아니라 **개정문 본문·부칙·대비표를 전수** 훑었다.
- [ ] 주택공급·건설·거래·취득·보유·임대·정비사업·토지·금융·세제를 넓게 검색했다.
- [ ] 직접 관련과 간접 관련을 모두 후보표에 올렸다.
- [ ] 개정이유에 없는 항(項)·목(目) 단위 신설과 적용기한 정비를 확인했다.
- [ ] 제외한 조문마다 `무관`·`순수 문구정비`·`사용자 제외` 등 이유가 있다.
- [ ] 실질효과가 불명확한 조문을 임의로 삭제하지 않았다.
- [ ] **직접 관련 신설조문을 명시적 제외 지시 없이 버리지 않았다.**

## 3. 법적 정확성

- [ ] 개정문과 신·구조문대비표를 서로 대조했다.
- [ ] 대상·요건·금액·비율·기간·권리의무가 원문과 일치한다.
- [ ] 법령명과 조문·항·호·목이 정확하다.
- [ ] **조문 표기가 `§92의2` 형식이다**(`§92조의2` 아님).
- [ ] **개정문의 처분문구를 기준으로** 개정·신설·삭제·이동을 조문별로 판정했다.
- [ ] 기존 항 이동과 새 항 신설을 혼동하지 않았다.
- [ ] 이유서·목차의 조문 표기가 개정문과 다를 때 **개정문을 따랐다.**
- [ ] 시행일·적용례·경과조치가 부칙과 일치한다.
- [ ] **상위 법률과 하위 법령의 시행일을 뒤섞지 않았다.**
- [ ] 각 수치·조건·날짜의 근거가 `법률안/부칙/하위법령안/정부자료` 중 하나로 추적된다.
- [ ] 법률안 밖 정보는 출처 주석을 붙였고, 근거 없는 정보는 제외했다.
- [ ] 계속 거주·보유, 재취득·재전입, 추징, 신청기한, 단기보유 비교과세, 취득 시기 하한, 계약금 납부분 포함 여부를 확인했다.
- [ ] 예외 조항의 **괄호 제한(예: "…는 제외한다")**을 빠뜨리지 않았다.
- [ ] 원문 간 충돌은 해소됐거나 `원문 확인 필요`로 표시됐다.

## 4. 구성과 압축

- [ ] 법령별 구성이 원칙적으로 유지됐다.
- [ ] 법령 안에서는 조문순이 아니라 중요도·정책주제 순이다.
- [ ] 같은 정책효과를 만드는 여러 조문이 적절히 통합됐다.
- [ ] 정책주제별 통합은 2개 이상 법령 분산 + 반복·분절 위험 + 추적 가능성을 모두 충족하고 **사용자 승인**을 받았다.
- [ ] **제목이 담은 대상·세목·개정방향을 본문에서 반복하지 않았다.**
- [ ] 본문 `◦`가 적용요건·효과·기한을 담고 있다.
- [ ] 항목당 주석이 1개 수준이다(2개 초과 시 본문 압축을 재검토).
- [ ] 표는 독자가 자기 값을 찾아 대조해야 할 때만 썼다. 열거형 예외를 표로 펼치지 않았다.
- [ ] 상호 참조는 번호가 아니라 **항목명**으로 했다.
- [ ] 한 법령당 통상 1쪽, 필요시 2쪽 수준으로 압축했다.

## 5. 객관성과 범위

- [ ] 개정내용만 객관적으로 설명했다.
- [ ] 협회 영향·평가·찬반·대응계획을 넣지 않았다.
- [ ] 전문가·언론 내용을 요청 없이 조사하거나 넣지 않았다.
- [ ] **대상 법령 범위 밖 자료(샘플·참고용 상위법 등)의 내용이 본문에 섞이지 않았다.**
- [ ] 추진 배경에 제공 자료로 확인되지 않는 상위 정책명을 넣지 않았다.
- [ ] 쉬운 설명이 법률상 의미를 바꾸지 않았다.
- [ ] 참고 샘플을 사용했다면 `sample-notes.md`의 확인된 오류를 재현하지 않았다.

## 6. 최종 처리

- [ ] 모든 미해결 사항을 사용자에게 알렸다.
- [ ] 명시적 최종 승인을 받았다.
- [ ] 승인 후 저장 위치를 확인했다.
- [ ] 동일 파일이 있는 경우 덮어쓰기 승인을 받았다.
- [ ] Markdown과 선택적 HTML의 내용·주석이 일치한다.
- [ ] 대번호가 `❶❷❸`으로 통일되어 있다.
