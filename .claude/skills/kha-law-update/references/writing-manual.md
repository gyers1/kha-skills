# 「개정안 주요내용」 작성 매뉴얼

## 1. 산출물의 성격

법률 검토의견서가 아니라 회원사 안내자료다. 독자는 개정문 전체를 읽지 않고도 `무엇이, 누구에게, 언제부터, 어느 정도 바뀌는지`를 파악해야 한다.

1. **원문 충실성** — 법적 효과와 수치를 임의 해석하지 않는다.
2. **넓은 주택 관련성** — 사업자 직접 규제뿐 아니라 주택 거래·수요·보유에 영향을 주는 조문도 본다.
3. **정책주제 중심 압축** — 조문 순서를 복사하지 않고 같은 정책효과를 묶는다.
4. **사용자 선별 가능성** — 1차 초안은 넓게, 최종본은 사용자 판단을 반영해 간결하게.

## 2. 원문 우선순위와 출처 관리

| 자료 | 역할 | 사용 원칙 |
| --- | --- | --- |
| 개정문 | 바뀌는 법 문언과 조문 구조 확정 | **법적 변경의 최종 기준** |
| 신·구조문대비표 | 현행 대비 차이 파악 | 대상·요건·수치·신설·삭제 교차확인 |
| 부칙 | 시행일·적용례·경과조치 확정 | 날짜를 추정하지 않음 |
| 개정이유·주요내용 | 입법 목적과 정책 단위 파악 | **보조자료.** 여기 없는 개정이 많음 |
| 입법예고문 | 공고번호·예고일 확인 | 추진 배경 작성 근거 |
| 보도자료·정책 상세본 | 하위법령 예정 수치 등 배경 | 원문보다 우선하지 않음 |

개정문과 대비표가 다르면 오류 가능성을 먼저 의심한다. 조문번호 이동 때문에 생긴 겉보기 차이인지 확인한 후에도 충돌하면 `원문 확인 필요`로 남긴다.

**이유서·주요내용 목차의 조문 표기가 개정문과 다르면 개정문을 따른다.** (실제 사례: 법인세법 시행령 이유서가 `안 제92조의2제1항`으로 표기했으나 개정문·대비표는 모두 `제92조의2제2항제1호의16`)

### 2.1 출처 태그 (내부 근거표 전용, 5종)

| 태그 | 의미 |
| --- | --- |
| `법률안` | 개정문 또는 신·구조문대비표에서 직접 확인 |
| `부칙` | 시행일·적용례·경과조치에서 직접 확인 |
| `하위법령안` | 시행령·시행규칙 개정안에서 확인 |
| `정부자료` | 세제개편 상세본·입법예고문·보도자료에서만 확인 |
| `확인필요` | 제공 자료에서 근거를 찾지 못함 |

최종 안내자료에 태그를 일괄 노출하지 않는다. 법률안 밖 정보가 핵심 설명에 필요할 때만 `※ 시행령 개정안 기준`처럼 한 줄로 표시한다. **근거자료가 제공되지 않은 정보는 쓰지 않는다.**

## 3. 주택 관련성 판정

### 3.1 직접 관련

- 주택·공동주택·오피스텔 등 주거용 건축물
- 주택건설사업자·주택조합·공공주택사업자·임대사업자
- 주택의 신축·분양·매매·임대·보유·양도
- 재개발·재건축·소규모주택정비사업
- 미분양주택·임대주택·세컨드홈·1세대 1주택 특례
- 주택담보대출·이주비·전세·월세·주택임차자금

### 3.2 간접 관련

- 주택건설용 토지의 취득·보유·양도·과세
- 비사업용 토지 및 종합합산·별도합산 토지 과세
- 수요자의 취득세·양도세·보유세·주거비 공제
- 분양 가능성, 거래 유동성, 지방 미분양 해소와 연결되는 특례
- 공공주택 공급을 위한 토지 양도 및 사업시행 지원

`시장에 영향을 줄 수 있다`는 평가문은 쓰지 않는다. 관련성 판정에만 쓰고 본문에는 개정 사실만 적는다.

### 3.3 제외와 보류

- **바로 제외**: 오탈자·띄어쓰기·표현정비만 있고 실질효과 없음
- **검토 후 제외**: 인용조문 정비나 항번호 이동으로 권리·의무가 바뀌지 않음
- **보류 후 확인**: 위임범위·적용대상·인용관계가 달라질 가능성 있음
- **사용자 선택**: 주택 관련성은 있으나 회원사 안내 비중이 낮은 개인 세액공제·납세절차

## 4. 후보 조문 전수표 작성법

각 법령의 **개정문 본문 → 부칙 → 신·구조문대비표**를 전수 훑는다. 개정이유 목차는 보조로만 쓴다.

> 개정이유·주요내용에 없는 개정이 흔하다. 적용기한 정비, 항(項) 단위 신설, 목(目) 추가는 목차에 안 나오는 경우가 많다.

### 필수 열

법령명·조문·항·호 / 개정유형 / 주택 관련성 / 현행 대비 핵심 차이 / 대상·요건·금액·비율·기간·절차 / 시행일·적용례·경과조치 / **근거 출처** / 1차 초안 반영 여부와 이유

`관련 있음`이라고만 쓰지 말고 경로를 한 구절로 적는다. 예: `수요자 주거비 공제`, `주택건설용 토지 보유세`, `지방 미분양 취득 특례`.

### 4.1 개정유형 판정

**개정이유 제목이나 샘플 표기가 아니라 개정문의 처분문구로** 조문 단위마다 판정한다.

| 개정문 처분문구 | 판정 |
| --- | --- |
| `제○조를 다음과 같이 신설한다`, `같은 조에 제○항을 신설한다`, `같은 호에 ○목을 신설한다` | **신설** |
| `○○ 중 A를 B로 한다`, `○○를 다음과 같이 한다`, 단서·후단을 고침 | **개정** |
| `○○를 삭제한다` | **삭제** |
| `제○항을 제○항으로 한다`(내용 변경 없음) | **이동** |
| `제○항을 제○항으로 하고, 같은 조에 제○항을 신설한다` | 이동과 신설을 **각각** 기록 |

- 기존 조항을 이동한 뒤 같은 번호에 새 조항을 넣는 경우, 새 번호 전체를 신설로 오인하지 않는다.
- 하나의 제목에 개정과 신설이 함께 있으면 `§104⑦ 개정·⑧ 신설`처럼 각각 표시한다.
- 대비표의 `<신 설>`·`<삭 제>`는 교차확인 수단이다. 개정문과 다르면 확정하지 않는다.

### 4.2 조문 표기 규칙

- `§`는 이미 "제○조"를 뜻한다. **`§92의2`가 맞고 `§92조의2`는 틀렸다**(제92조조의2가 됨).
- 항·호·목은 원문 단위를 유지한다: `§4의3③3호바목2)`
- 제목에는 **본문 설명을 직접 뒷받침하는 조문만** 넣는다. 반대로 적용대상·추징조건을 설명했다면 그 근거 조문을 빠뜨리지 않는다.

### 4.3 핵심 조건의 누락 방지

적용 여부나 환수 결과를 바꾸는 다음 조건은 1차 후보표에 반드시 기록한다.

- 계속 거주·보유·임대기간
- 재취득·재전입 제한
- 감면세액 추징·이자상당가산액
- 신청·신고기한 (신청주의 도입 여부)
- 단기보유 비교과세
- 공동소유·분할양도의 한도 안분
- 취득 시기 하한, 매매계약 체결·계약금 납부분 포함 여부

최종본에서 세부조건을 줄이더라도 **법적 효과를 뒤집는 조건은 `※` 또는 `*` 한 줄로 남긴다.**

## 5. 개정효과 추출법

조문별로 답한다.

1. **누가** — 개인·법인·1주택자·다주택자·사업자·고령자
2. **무엇을** — 주택·토지·임대소득·양도차익·과세표준
3. **어떤 요건이** 생기거나 사라지는가
4. **어떤 수치가** — 세율·한도·기간·면적·가격
5. **어떤 법적 결과가** — 과세·공제·감면·배제·유예·신고
6. **언제부터 어떤 건에** 적용되는가

## 6. 분류와 배열

### 6.1 기본은 법령별

각 법령을 대번호로 두고 그 안에서 정책주제를 소번호로 묶는다. 법령별 책임소재와 시행·적용 조항을 추적하기 쉽다.

**법령 간 순서 기본값**: 개인 세제(소득세) → 보유세(종부세) → 법인 세제(법인세). 회원사 관심도가 뚜렷이 다르면 조정할 수 있다.

### 6.2 법령 안에서는 중요도·정책주제별

원문 조문 순서를 따르지 않는다. 우선순위 기본값:

1. 주택 거래·공급·보유 전반에 미치는 변화
2. 과세부담과 적용대상 변화
3. 특례의 신설·폐지·대폭 확대 또는 축소
4. 주요 요건·한도·기간 변경
5. 신청·신고·납부 등 절차 변경
6. 기술적 정비

주택공급·거래 활성화와 직접 연결되는 개정은 조문 뒤쪽에 있어도 앞으로 올릴 수 있다. 다만 `중요하다`, `긍정적이다` 같은 평가를 붙이지 않는다.

### 6.3 여러 조문을 하나로 묶는 기준

세 조건이 모두 맞으면 한 항목으로 통합한다.

- 정책 목적이 같다
- 적용대상 또는 법적 효과가 이어진다
- 따로 쓰면 독자가 중복으로 느낀다

예: 장기공제의 명칭 변경·공제방식 변경·한도 신설 → `장기보유특별공제 이원화 및 거주 중심 개편`

반대로 **대상·효과·시행일 중 하나가 크게 다르면 나눈다.** 조문 하나 = 항목 하나가 기본 입도다.

### 6.4 정책주제별 통합모드

다음을 **모두** 충족할 때만 제안한다.

1. 동일한 정책효과가 **2개 이상 법령**에 분산되어 있다
2. 법령별로 쓰면 같은 대상·수치·설명을 반복하거나, 한 법령만 읽어 전체 효과를 오해할 수 있다
3. 통합해도 각 법령의 조문과 시행·적용관계를 정확히 추적할 수 있다

**법령이 2개 이상이라는 사실만으로 자동 통합하지 않는다.** 대상·효과·시행일이 다르면 법령별 구성을 유지한다.

- 통합 적합 예: 소득세법·법인세법·종부세법에 흩어진 `비사업용 토지 과세 강화`
- 통합 부적합 예: 서로 다른 주거비 공제 (법령별 설명이 더 명확)

기본값이 아니다. 전환 이유와 예상 대번호를 먼저 보여주고 **승인을 받은 후** 사용한다.

법령별 구성을 유지하면서 중복만 없애려면, 뒤쪽 항목에서 **번호가 아니라 항목명으로** 참조한다.
`* 적용기한은 앞의 '매입임대 아파트 양도세 중과배제 기한 설정'과 동일` (○)
`* ❶②와 동일` (×, 순서가 바뀌면 깨짐)

## 7. 제목·본문·주석의 역할 분리

**압축은 내용을 빼는 것이 아니라 역할을 나눠 정보 밀도를 높이는 것이다.**

| 요소 | 담는 것 |
| --- | --- |
| **제목** | 대상 · 세목 · 개정 방향 |
| **본문 `◦`** | 적용요건 · 효과 · 기한 |
| **주석 `*` `※`** | 본문 흐름을 끊는 예외만, 최소한으로 |

### 7.1 제목이 말한 것을 본문에서 반복하지 않는다

제목: `매입임대 아파트 법인세 추가과세 배제기한 설정`

- (×) `◦ 기한 없이 적용되던 조정대상지역 소재 매입임대 아파트의 법인세 추가과세 배제를 적용기한 내 양도분으로 한정`
  → 제목의 `매입임대 아파트`, `법인세 추가과세 배제`, `기한 설정`을 그대로 되풀이함
- (○) `◦ 조정대상지역 소재 매입임대 아파트는 ’27년말까지 양도분에 한해 배제 적용(예외* 해당 시 1년 연장)`
  → 같은 줄 수에 **적용요건(조정대상지역 소재)과 기한(’27년말)**이 들어감

### 7.2 결론형 제목

개정 방향과 대상을 동시에 보여준다.

- 좋은 예: `다주택자 양도세 중과 한시 완화`, `조정대상지역 일시적 2주택 처분기한 1년 단축`
- 나쁜 예: `양도소득세 관련 개정`, `제104조 개정사항`

제목 끝 괄호에 근거 조문과 개정유형을 적는다.

### 7.3 핵심문장

첫 문장은 `대상 + 변화 + 핵심 수치/시기` 순. 세부 예외가 많으면 본문을 늘이지 말고 `*` 한 줄로 뺀다.

법률용어를 없애지 말되 쉬운 설명을 괄호로 보충할 수 있다.
`종부세 합산배제(과세표준 합산 대상에서 제외)`, `세부담 상한(전년 대비 세액 증가 한도)`

변화 표기는 짧게: `(’26 → ’27년말 취득분)`, `10% → 15%`

### 7.4 수치 주석

- 본문: 방향과 대표 수치
- 표: 대상·시기별 전체 비교
- 주석: 예외·전제·적용범위

같은 숫자를 제목·본문·표에 반복하지 않는다.

## 8. 표 선택 기준

### 표로 만드는 경우

**독자가 자기 값(보유주택 수, 과세표준 구간, 연도)을 찾아 대조해야 할 때만** 쓴다.

- 세율·한도·공제율이 구간별로 다르다
- 연도별·대상별로 값이 각각 다르다
- 현행/개정안 외에 축이 하나 더 있고, 그 축의 값마다 결과가 다르다

### 문장·주석으로 쓰는 경우

- 단일 수치가 한 번 바뀐다
- 적용기한이 1회 연장된다
- 신설·삭제 효과가 한 문장으로 명확하다
- **열거형 예외** — 사유가 여러 개라도 결과가 같으면 축이 둘이어도 각주 한 줄로 쓴다

> 예: 적용기한 예외 3사유(임대의무기간 종료 / 조정대상지역 신규지정 / 재건축·재개발)는 결과가 모두 `1년 연장`이므로 표가 아니라
> `(예외* 해당 시 1년 연장)` + `* ’27년 이후 임대의무기간 종료, 조정대상지역 신규지정(’26년말 기준 지역 제외), 재건축·재개발 시행 주택 — 해당 사유일 중 가장 늦은 날부터 1년`

다단 세율표처럼 병합 셀이 필수일 때만 HTML 표를 쓴다. HWP 붙여넣기에서 깨지지 않는 단순 구조를 우선한다.

## 9. 시행일·적용례·경과조치

### 9.1 세 개념 구분

- **시행일**: 개정 규정이 효력을 갖기 시작하는 날
- **적용례**: 시행 후 어떤 소득·양도·취득·납세의무 성립분부터 적용하는지
- **경과조치**: 종전 행위·계약·취득분에 어떤 규정을 적용하는지

### 9.2 배치

- 법령별 시행일이 같으면 **해당 법령 끝에 한 줄**: `※ 시행일 : ’26.10.1. (①·②는 시행 이후 양도분부터 적용)`
- 항목별 날짜가 여러 개면 법령 끝에 3열 표
- 특정 항목만 특별한 경과조치가 있으면 해당 항목 아래에도 `※`
- 여러 법령 일정이 지나치게 복잡하면 별첨을 제안하되, 승인해야 본문에서 상세 일정을 뺄 수 있다

부칙 문구가 없으면 보도자료의 시행 예정일을 확정 시행일처럼 쓰지 않는다.

> **주의**: 상위 법률과 하위 시행령의 시행일이 다른 경우가 흔하다. 시행령 시행일을 법률 조문에 붙이지 않는다.

## 10. 추진 배경

정책평가가 아니라 문서 발생 경위를 알려주는 한 문장.

`▪ [대상 법령] 개정안이 [입법예고일] 입법예고됨에 따라, [주택 관련 개정내용]을 안내`

- 공고번호는 근거가 있을 때만 각주 또는 문장 끝에 붙인다.
- **제공 자료에 없는 상위 정책명(예: 「○○년 세제개편안」 후속)을 추론해 넣지 않는다.**
- 법령이 많아도 나열하지 말고 `주요 세법 4건`처럼 압축한 뒤 각주로 풀 수 있다.

## 11. 1차 초안과 최종본의 차이

### 1차 초안

- 관련성 범위를 넓힌다
- 경계 항목도 포함하거나 `검토 필요`로 표시한다
- 후보를 숨기지 않는다
- 법령 구조보다 회원사 관점의 중요순서를 먼저 제시한다

### 2차·최종본

- 사용자가 제외한 항목을 뺀다
- 남은 항목을 정책주제별로 재통합한다
- 반복 설명과 과도한 예외를 주석으로 압축한다
- 객관적 개정내용과 조문·시행·적용 근거는 유지한다

**처음부터 샘플과 항목 수를 똑같이 맞추는 것은 실패다.** 샘플을 참고할 때는 반드시 `sample-notes.md`를 먼저 읽고 확인된 오류를 재현하지 않는다.

## 12. 사실확인 도구 사용

사용자가 제공한 법령안을 다시 인터넷에서 찾지 않는다. 다음 경우에만 `korean-law-mcp`를 쓴다.

- 개정안이 인용하는 현행 조문의 전체 문맥이 필요할 때
- 다른 법률에 정의·위임된 용어의 의미를 확인할 때
- 조문번호 이동으로 현행 구조를 확인해야 할 때
- 특정 기준일의 적용 법령·개정이력을 확인해야 할 때
- 조문 인용이 정확한지 검증할 때

현행 조문은 `search_law`·`get_law_text`, 여러 법령 관계나 기준일별 적용법은 `legal_research`·`legal_analysis`를 우선한다. 도구 결과와 사용자 원문이 다르면 차이를 알리고 원문 확정을 요청한다.

전문가 평가·언론 기사는 사용자가 명시적으로 요청할 때만 조사한다.

## 13. 저장과 후속 산출물

Markdown이 정본이다. HTML은 정본의 내용·표·각주를 그대로 옮기고 단순 흑백 스타일만 입힌다. 사용자가 HWP에서 별도 편집하므로 인쇄 여백·페이지 강제분할에 시간을 과도하게 쓰지 않는다.

대번호 문자는 `❶❷❸`을 쓴다. HWP 전용 문자(`󰊱`)는 브라우저에서 깨지므로 HTML에서 쓰지 않는다.

최종 승인 후에만 파일을 만들고 저장 위치를 확인한다. 이후 임원요약·협회 영향·검토의견이 필요한지 묻되 자동으로 작성하지 않는다.
