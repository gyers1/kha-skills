# 개정안 주요내용 기본 틀

복사본이 아니라 산출 구조다. 개정 규모와 정책주제에 맞춰 항목 수와 표를 조정한다.

## 기본형 (법령별 구성)

```markdown
「대상 법령명 또는 주제명」 주요내용

< 추진 배경 >

▪ [대상 법령] 개정안이 [입법예고일] 입법예고됨에 따라 주택 관련 주요 개정내용을 안내

□ 주요내용

❶ [법령 정식명칭]

 ① [결론형 제목]([법령 약칭] §조문·항 개정/신설/삭제)

  ◦ [적용요건 + 효과 + 기한을 한 문장으로]

  * [본문 흐름을 끊는 예외·전제만]

 ② [다음 결론형 제목](§조문)

  ◦ [핵심 변화]

  * [예외]

 ※ 시행일 : [날짜] ([일부 항목만 적용례가 다르면 괄호로])

❷ [다음 법령]

 ① …
```

## 제목 규칙

- `지원 확대`, `과세 강화`, `요건 완화`, `특례 폐지`, `기한 설정`, `1년 단축`처럼 **변화의 결론이 먼저** 보이게 쓴다.
- `○○법 개정`, `제95조 개정`처럼 내용 없는 제목은 피한다.
- 제목은 `대상 · 세목 · 개정 방향`을 담는다. **본문에서 이를 되풀이하지 않는다.**
- 하나의 제목 아래 여러 조문을 묶을 수 있다. 이 경우 근거 조문을 모두 적는다.
- 개정유형이 섞이면 `§104⑦ 개정·⑧ 신설`처럼 조문별로 구분한다.
- 조문 표기는 `§92의2`(○) / `§92조의2`(×).
- 법령명은 처음 정식명칭, 이후 `소득세법`·`조특법`·`법인세법`·`종부세법`, 시행령은 `소득령`·`법인령`·`종부령` 약칭을 쓸 수 있다.

## 본문 규칙

- `◦`는 적용요건·효과·기한을 담는다. 통상 1줄, 길어도 2줄.
- 변화는 짧게 표기한다: `(’26 → ’27년말 취득분)`, `3년 → 2년`, `10% → 15%`
- 현행값이 필요하면 괄호로 붙인다: `… 2년 내 양도해야 비과세 적용(현행 3년)`

## 주석 규칙

- `*` — 본문 흐름을 끊는 예외·전제·적용범위
- `※` — 시행일·적용례·경과조치
- 항목당 주석은 1개를 목표로 한다. 2개를 넘으면 본문 압축이 잘못된 것이다.
- 열거형 예외는 `— 해당 사유일 중 가장 늦은 날부터 1년`처럼 결과를 뒤에 붙여 한 줄로 만든다.

## 표 규칙

- **독자가 자기 값을 찾아 대조해야 할 때만** 쓴다(세율 구간, 연도별·대상별 값).
- 사유가 여러 개라도 결과가 같으면 표가 아니라 각주 한 줄로 쓴다.
- 단순한 한 값 변경은 `10% → 15%`처럼 문장으로 쓴다.
- 병합이 필요 없으면 Markdown 표를 쓴다. 다단 헤더·병합 셀이 필요할 때만 최소한의 HTML 표를 쓴다.
- 표가 너무 넓으면 시기별·대상별로 나누고 조건·예외는 표 아래 `※`로 뺀다.

## 추진 배경 규칙

- 한 문장.
- 기본 포함: 대상 법령, 입법예고일, 안내 목적.
- 공고번호는 제공 자료에 있을 때만 넣는다.
- **제공 자료에 없는 상위 정책명을 추론해 넣지 않는다.**
- 의견제출 기한은 요청한 경우에만 넣는다.

## 출처와 조건 규칙

- 법률안·대비표·부칙에서 직접 확인한 내용과 하위법령안·정부자료 내용을 내부 근거표에서 구분한다.
- 법률안 밖 수치가 핵심 설명에 필요하면 근거자료를 확보하고 `※ 시행령 개정안 기준` 등 최소한의 출처 주석을 붙인다.
- 근거를 찾지 못한 수치·날짜·대상은 본문에 쓰지 않고 `추가 자료 필요`로 알린다.
- 감면·특례의 적용을 좌우하는 계속 거주, 재취득·재전입, 추징, 신청, 취득 시기 하한, 계약금 납부분 포함 여부는 제목을 늘이지 말고 `*` 한 줄로 남긴다.

## HTML 산출 규칙

- Markdown 정본과 내용·주석이 완전히 일치해야 한다.
- 흑백만 쓴다. 음영은 `#f2f2f2` 수준의 회색 하나로 제한한다.
- 인라인 CSS 대신 `<style>` 블록을 쓰되, flexbox·grid는 쓰지 않는다(HWP 붙여넣기 시 깨짐).
- 대번호는 `❶❷❸`. HWP 전용 문자 `󰊱`는 브라우저에서 깨지므로 쓰지 않는다.
- `@media print`로 법령 헤더 뒤 페이지 끊김과 표 중간 분할을 막는다.
